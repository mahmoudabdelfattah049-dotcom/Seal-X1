# إعداد وكلاء الذكاء الاصطناعي في Seal X1

## الحالة

- Edge Function: x1-ai-agent (JWT required).
- قاعدة المعرفة: x1_ai_knowledge.
- دليل أقسام المنصة: x1_platform_catalog.
- سجل المحادثات: x1_ai_conversations و x1_ai_messages.
- حدود الاستخدام: 40 طلباً لكل مستخدم خلال 24 ساعة، و6 طلبات خلال 5 دقائق.

## تفعيل نموذج الذكاء الاصطناعي

1. افتح مشروع Seal X1 في Supabase Dashboard.
2. افتح Edge Functions ثم Secrets.
3. أضف سراً جديداً بالاسم OPENAI_API_KEY، وضع قيمة مفتاح API فيه.
4. احفظ السر. لا تضع المفتاح في index.html أو script.js أو GitHub أو رسائل المحادثات.
5. اختبر المساعد بعد تسجيل الدخول بحساب طالب أو معلم.

مفتاح API لا يُرسل إلى المتصفح؛ وظيفة Supabase تقرؤه من متغير البيئة على الخادم فقط. فوترة API منفصلة عن اشتراك ChatGPT.

## النماذج الافتراضية

- QUREO: gpt-6.1-sol مع مستوى استدلال مرتفع.
- المساعد العام: gpt-6.1-terra مع مستوى استدلال متوسط.
- يمكن تغييرهما عبر الأسرار X1_QUREO_MODEL و X1_GENERAL_MODEL.

## ما الذي يصل إلى نموذج الذكاء الاصطناعي؟

- سؤال المستخدم وسياق المحادثة السابقة في نفس محادثته.
- QUREO: مقتطفات من قاعدة المعرفة البرمجية.
- المساعد العام: دليل أقسام المنصة، عناوين الإعلانات والموارد المنشورة، وفهرس الفيديوهات.
- لا تُرسل كلمات المرور أو مفاتيح Supabase أو سجلات الزيارات أو الرسائل الخاصة لمستخدمين آخرين.

تُحفظ محادثات المستخدم في جداول X1 AI حتى يتمكن المساعد من متابعة السياق. لا تكتب في المحادثة بيانات شخصية أو كلمات مرور.

## تحديث قاعدة المعرفة

أضف وثائق جديدة إلى public.x1_ai_knowledge، مع تحديد agent='qureo' أو agent='general' أو agent='both'، واجعل is_published=true بعد مراجعة المحتوى. الفهرس النصي يتحدث تلقائياً عند تعديل العنوان أو المحتوى.

حدّث public.x1_platform_catalog عند إضافة قسم أو زر جديد أو تغيير صلاحياته. يجب أن يطابق section_id قيمة id الفعلية في الواجهة، وأن تكون allowed_roles دقيقة.

## اختبارات قبول يدوية

### QUREO Mentor
- شرح الفرق بين = و ===.
- شرح HTML الدلالي.
- توسيط بطاقة باستخدام Flexbox.
- تحليل حلقة JavaScript فيها خطأ في شرط التوقف.
- فهم سؤال عامي به أخطاء إملائية.
- عدم اختراع رقم فصل مصري أو ادعاء تشغيل الكود.

### X1 Guide
- طالب: «عايز أشوف درجاتي» → قسم التقدم.
- طالب: «افتح فيديو الغلاف المائي» → الفيديو المطابق إن وُجد.
- طالب: «الإعلانات فين؟» → الإعلانات.
- معلم: «أرفع PDF إزاي؟» → نموذج إضافة ملف أو مصدر.
- طالب يطلب إجراء خاص بالمعلم → لا يكشف له الأدوات المحجوبة.
- سؤال ملتبس → سؤال توضيح واحد بدلاً من تخمين قسم.

## ملاحظة

المساعدان يقدمان البحث والتوجيه والشرح، ولا ينفذان نشر أو حذف أو تعديل بيانات المنصة. أي قدرة تنفيذية حساسة يجب أن تُضاف كأداة منفصلة مع تحقق صلاحيات وموافقة بشرية.
