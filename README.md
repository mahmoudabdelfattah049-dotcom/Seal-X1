# Seal X1

بوابة تعليمية مدرسية باللغة العربية، مبنية باستخدام HTML وCSS وJavaScript.

## تشغيل محلي
افتح `index.html` في المتصفح.

## النشر على GitHub Pages
المشروع يحتوي على GitHub Actions workflow للنشر التلقائي. من إعدادات المستودع افتح **Settings → Pages** واجعل **Build and deployment → Source** على **GitHub Actions** إذا لم يكن مضبوطاً بالفعل.

## حالة المشروع
هذه النسخة واجهة أمامية ثابتة. أقسام الإعلانات وQUREO والملفات والفيديوهات جاهزة لإضافة المحتوى، لكنها لا تحتوي بعد على قاعدة بيانات أو تسجيل دخول أو لوحة نشر للمدرسين. يلزم تطوير خلفية ومصادقة قبل تفعيل النشر الفعلي للمدرسين.

الموقع مصمم ليعمل على الهاتف والكمبيوتر، ويدعم الوضع الفاتح والداكن.
