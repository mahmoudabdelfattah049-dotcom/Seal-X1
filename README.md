# Seal X1

بوابة تعليمية مدرسية باللغة العربية، مبنية باستخدام HTML وCSS وJavaScript، مع Supabase للمصادقة والبيانات.

## تشغيل محلي
افتح `index.html` في المتصفح. يتطلب تشغيل الوظائف المتصلة إعداد مشروع Supabase وقيم الاتصال العامة المستخدمة في الواجهة.

## النشر على GitHub Pages
المشروع يحتوي على GitHub Actions workflow للنشر التلقائي. من إعدادات المستودع افتح **Settings → Pages** واجعل **Build and deployment → Source** على **GitHub Actions** إذا لم يكن مضبوطاً بالفعل.

## بنية المنصة
- ثلاثة أدوار أساسية: مدير، معلم، طالب.
- إدارة الحسابات والمحتوى من مساحات مخصصة حسب الدور.
- الإعلانات المدرسية تعمل عبر جدول `school_announcements` مستقل، مع قراءة عامة للإعلانات المنشورة فقط، وكتابة محمية بسياسات RLS.
- يتم تحديث موجز الإعلانات عند التغييرات عبر Supabase Realtime، مع تحديث دوري احتياطي.
- محتوى المدرسة والموارد التعليمية منفصل عن بيانات الامتحانات والمحادثات.

## ملاحظات
المفتاح الموجود في الواجهة هو Publishable Key مخصص للعميل؛ لا تضع مفاتيح Service Role أو كلمات مرور أو أسراراً في ملفات الموقع.
الموقع متجاوب مع الهاتف والكمبيوتر ويدعم الوضع الفاتح والداكن.
